# Simple Analog Clock for PC

버전 0.1.13 · Windows, macOS, Linux용 아날로그 데스크톱 시계

Windows x64 배포본은 `Simple Analog Clock for PC.exe`를 실행하면 됩니다. 이 소스에서 직접 빌드하는 방법은 아래에 있습니다.

- 시계를 왼쪽 버튼으로 드래그하면 이동합니다. Windows에서는 드래그 중에도 가장자리 가까이 가면 시계가 붙고, 안쪽으로 끌면 떨어집니다. `옵션`의 `가장자리 붙이기`에서 끌 수 있습니다.
- 시계를 우클릭하면 메뉴가 마우스의 오른쪽 아래에 열립니다. `항상 위`는 Windows와 macOS의 최초 실행 시 켜져 있습니다. Linux 빌드에는 이 항목이 포함되지 않습니다.
- 우클릭 메뉴의 `불투명도`에 마우스를 올리면 옆에 20%, 40%, 60%, 80%, 100%가 나타납니다. 기본값은 100%입니다.
- `옵션` 창은 공간이 충분하면 시계 왼쪽에 열립니다. `디자인` 목록에서 아이보리, 차콜, 네이비를 고르고, `바늘 모양`에서 두툼하거나 뾰족한 시침과 분침을 선택할 수 있습니다. `시간 기준`은 기본값인 현재 컴퓨터 시간 또는 지정한 IANA 시간대를 사용합니다. 목록에서 `Seoul`처럼 도시 이름으로 검색할 수 있습니다.
- `옵션`의 첫 항목인 `시계 크기`에서 시계판 지름을 116~400px로 조정할 수 있습니다. `시계 크기`의 기본값은 116px입니다.
- `테두리 두께`의 기본값은 4px입니다. 바깥 테두리를 2~14px로 조절하거나, `자동`을 선택해 시계 지름에 비례하도록 설정할 수 있습니다. 고정 두께를 변경하면 안쪽 시계판 크기를 유지한 채 바깥 지름이 바뀝니다.
- 바늘 모양과 두께의 기본값은 `뾰족`, 110%입니다. `디자인` 바로 아래의 `바늘 두께`에서 시침·분침을 50~200%로 조절할 수 있습니다. 초침은 화면 배율 100%에서 앞쪽 1px, 뒤쪽 3px입니다.
- `바늘 두께` 아래의 `숫자 표시`에서 숫자를 켜고 끌 수 있습니다. `숫자 글꼴`에서는 기본 글꼴인 Roboto Condensed와 Clock Sans KR, Oswald, Noto Serif, IBM Plex Mono를 선택할 수 있습니다. `글꼴 크기`는 100%가 기본값이며 70~125%로 조절합니다. `굵게`와 숫자 표시는 기본으로 켜져 있습니다.
- 슬라이더에 마우스를 올리고 휠을 돌리거나, 슬라이더에 포커스를 둔 상태에서 방향키를 눌러 조절할 수 있습니다.
- `초기화`를 클릭하면 옵션을 기본값으로 되돌립니다. `확인`에서 저장하고 `취소`에서 변경을 취소합니다.
- `확인(Enter)`을 클릭하거나 Enter를 누르면 옵션을 적용합니다. 설정은 실행 파일과 같은 폴더에 같은 이름의 `.ini` 파일로 저장됩니다. INI 파일을 삭제하면 다음 실행에 기본값으로 시작합니다.

## 소스 빌드

Rust 1.88 이상과 대상 플랫폼의 네이티브 빌드 도구가 필요합니다. Windows에서 MSVC Rust 도구를 사용한다면 Visual Studio의 C++ 빌드 도구와 Windows SDK를 설치합니다. 프로젝트 폴더에서 다음 명령을 실행합니다.

```sh
cargo build --release --locked
```

Windows에서는 `target/release/simple-analog-clock.exe`가 생성됩니다. macOS와 Linux에서는 `target/release/simple-analog-clock`이 생성됩니다.

Clock Sans KR은 Noto Sans KR의 일부 글자를 추려 이름을 바꾼 글꼴입니다. 각 글꼴의 SIL Open Font License는 `assets` 폴더의 `OFL*.txt`에 포함되어 있습니다.
